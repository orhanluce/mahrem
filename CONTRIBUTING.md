# Katki

Katkilar aciktir. Yeni bir tespit kurali eklerken:

1. Gercek kisi verisi kullanmayin; sentetik fikstur ekleyin.
2. Yanlis pozitif ve yanlis negatif testleri birlikte yazin.
3. Arac yanitlarinda ham deger sizmadigini test edin.
4. `py -3 -m unittest discover -s tests -v` komutunu calistirin.

Buyuk mimari degisiklikler icin once kisa bir issue acilmasi tercih edilir.
